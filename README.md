# QML Calculator

A simple calculator built with Qt Design Studio and QML.

## Features
- Basic operations: addition, subtraction, multiplication, division
- Clear (C), plus/minus (±) and percent (%) buttons
- Decimal number input

## Tech
- QML, Qt Quick
- Qt Design Studio (Qt 6.8)
